What "arbitrated against GIAB" means

The exome is not truth — it is a second fallible assay. So when the two callsets disagree at a site, "disagreement" alone cannot tell you who is wrong. Each discordant site is therefore looked up in the GIAB HG002 v5.0q truth set — the community gold standard for this exact sample — inside GIAB's high-confidence region (1.297 Mb), where GIAB has a defensible answer. That verdict is the ✓ / ✗ / ? column in the report:

VerdictMeaning
✓ GIAB confirms the caller that made the call the variant is real — so the other assay genuinely missed it
✗ GIAB refutes it the call is a false positive — the assay that skipped it was right
? outside GIAB high-confidence GIAB has no answer there (e.g. PAR1 on chrX) — counted, but not judged

This is why the report can say things like "one of the TSO500's apparent misses is actually a WES error" — that conclusion comes from GIAB, not from the two assays arguing with each other.

Consistency with the sibling projects. ../benchmark and ../benchmark_WES score against GIAB v4.2.1, so each discordance is also checked against v4.2.1 — the extra v4 ✓ / v4 ✗ / v4 — column in the discordance tables below. On every site v4.2.1 can judge, it returns the identical verdict as v5.0q — never a conflict. v4 — means only that v4.2.1 has no high-confidence answer there: either a chrX site (GRCh37 v4.2.1 is autosomes-only, chr1–22) or an autosomal site outside v4.2.1's high-confidence region (v5.0q's is broader). v5.0q stays the primary arbiter precisely because its reach is wider — two exome errors here (X:47045687, 16:2607730) sit exactly where v4.2.1 cannot reach.

Method provenance — where each choice comes from

ChoiceGrounding
rtg vcfeval as the matching engine The engine recommended by the GA4GH benchmarking framework (Krusche et al., Nat Biotechnol 2019). It resolves variant-representation differences by haplotype comparison, not naive position matching.
--squash-ploidy (allele-level) The TSO500 is tumor-only somatic and emits placeholder genotypes (0/1 at AF = 1.0). A genotype-aware score would measure the placeholder, not the assay.
bcftools norm -m -any GA4GH best practice: left-align and split multiallelics before comparison, so indel representation cannot create phantom discordances.
MNV decomposition + PASS-preferring de-dup Required by DRAGEN's documented MNVTAG component-call emission. Cross-validated two independent ways every run.
PPA / PPV wording, not sensitivity FDA Statistical Guidance on Reporting Results from Studies Evaluating Diagnostic Tests: against a non-reference standard, report agreement, not accuracy.
95% Wilson CIs A point estimate near 100% is not interpretable without an interval, and the normal approximation would overshoot 100%.
Arbitration against GIAB The same FDA guidance: "agreement is not a measure of correctness." GIAB is the only true reference available.

Known gap: GA4GH best practice also stratifies errors by genome context (GIAB stratification BEDs — homopolymers, low-complexity, segmental duplications). With only a handful of discordances here that would be n≈1 per stratum, so it is deliberately omitted. Add it if this is ever run on a sample with more disagreement.
